# Implementation Plan: Ionic Capacitor Web App

**Branch**: `002-ionic-capacitor-webapp` | **Date**: 2026-05-27 | **Spec**: [spec.md](specs/002-ionic-capacitor-webapp/spec.md)
**Input**: Feature specification from `/specs/002-ionic-capacitor-webapp/spec.md`

## Summary

Convert the CorvusBank Kids Banking App from React Native/Expo to an **Ionic React + Capacitor** cross-platform application, reusing the existing Firebase backend (Auth, Firestore, Cloud Functions). The first deliverable is a **web deployment** — a responsive SPA accessible via any modern browser. The architecture is Capacitor-ready for future native iOS/Android packaging.

The existing mobile app's business logic (auth credential mapping, Firestore CRUD, real-time subscriptions, finance utilities) will be ported directly into the new Ionic React project. The UI will be rebuilt using Ionic's component library for a professional, kid-friendly experience.

## Technical Context

**Language/Version**: TypeScript 5.x, React 19, Ionic React 8  
**Primary Dependencies**: `@ionic/react`, `@ionic/react-router`, `react-router-dom@5`, `firebase@^12.12.1`  
**Storage**: Firestore (shared collections: `users`, `accounts`, `transactions`)  
**Testing**: Vitest + React Testing Library  
**Target Platform**: Web browsers (Chrome, Firefox, Safari, Edge) + future Capacitor native (iOS/Android)  
**Project Type**: Hybrid SPA (web-first, Capacitor-native-ready)  
**Performance Goals**: Dashboard render < 2 seconds after login (SC-003)  
**Constraints**: Online-only (FR-014), persistent auth sessions (FR-015), max $10,000/deposit (FR-005), React Router v5 required by `@ionic/react-router`  
**Scale/Scope**: 4 pages (Login, SignUp, Dashboard, AccountDetails), 1 modal (Deposit), 1 overlay (Offline), ~15 source files

```text
webapp/                      # [NEW] Ionic Capacitor web application

│   ├── services/
│   │   ├── firebase.ts      # Firebase app + auth + Firestore initialisation
│   │   ├── auth.ts          # register, login, logout (fake email + padded PIN)
│   │   ├── authContext.tsx   # React context for auth state
│   │   └── db.ts            # Firestore CRUD + real-time subscriptions
│   └── utils/
│       └── finance.ts       # formatCurrency, calculateDailyInterest
└── tests/                   # Vitest test files (future)
```

**Structure Decision**: A new `webapp/` subdirectory isolates the Ionic project from the existing React Native codebase. This avoids bundler conflicts (Vite vs Metro), allows independent dependency trees, and lets both applications coexist during the transition period. The shared Firebase backend requires no structural changes.
